# Project guidance

This is the public MALCO reproducibility code. Follow README.md and QUICKSTART.md for the runnable synthetic demonstration. The code is not a clinical deployment.

Preserve the distinction between synthetic fixtures, newly trained demo artifacts, historical research models and actual clinical results. Do not modify or upload confidential patient data or manuscripts. Outcomes and Days_to_* must never enter the 41-predictor model schema.

Use the shared schema and artifact contract. Run the Python, Node and relevant R checks after changes. Treat live-provider verification separately from offline tests. Publishing or pushing requires the user's instruction.
